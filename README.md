# README

## Структура проекта

**app** - основное приложение
- Порт: 8080
- Зависит от PostgreSQL и миграций
- Авторестарт при ошибках

**migrator** - запуск миграций БД
- Выполняется один раз при старте
- Зависит от PostgreSQL

**postgres** - база данных
- Порт: 5432
- Volume для данных
- Health check


## Инструкция по запуску

### Быстрый запуск через Docker Compose

Сервис и все зависимости поднимаются одной командой:

```bash
docker-compose up
```

Сервис будет доступен на порту `8080`.

## Конфигурация

Конфигурация задается через переменные окружения:

- `PG_DSN` - строка подключения к PostgreSQL
- `HTTP_HOST` - хост для HTTP сервера (по умолчанию `0.0.0.0`)
- `HTTP_PORT` - порт для HTTP сервера (по умолчанию `8080`)
- `PG_DATABASE_NAME` - имя базы данных (по умолчанию `avito_pr`)
- `PG_USER` - пользователь PostgreSQL (по умолчанию `postgres`)
- `PG_PASSWORD` - пароль PostgreSQL (по умолчанию `postgres`)

## Технологии

- **PostgreSQL драйвер**: [pgx/v5]
- **Транзакции**: [go-transaction-manager-avito-tech](https://github.com/avito-tech/go-transaction-manager)
- **Логирование**: [zap] + [lumberjack]
- **Тестирование**: [testify]
- **Моки**: [mockery]
