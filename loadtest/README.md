# Нагрузочное тестирование

## Описание

Нагрузочное тестирование выполняется с помощью [vegeta]

## Установка

```bash
go install github.com/tsenart/vegeta/v12@latest
```

## Запуск

### Простой запуск
```bash
make loadtest
```

### Прямой запуск
```bash
go run loadtest/loadtest.go
```

## Сценарий тестирования

Тест выполняет умеренную нагрузку:
- **5 запросов в секунду (RPS)** в течение **5 минут**
- Всего ~1,500 запросов
- Объём данных: до 20 команд и до 200 пользователей

### Тестируемые эндпоинты:

- `POST /team/add` - создание команды
- `GET /team/get` - получение команды
- `POST /users/setIsActive` - установка статуса пользователя
- `POST /pullRequest/create` - создание PR
- `GET /stats` - получение статистики

## SLI (Service Level Indicators)

- **Время ответа (P95)**: < 300 мс
- **Успешность запросов**: >= 99.9%

## Отчеты

После выполнения теста генерируются отчеты:

- `loadtest/summary.json` - JSON отчет со всеми метриками
- `loadtest/summary.html` - HTML отчет для визуализации
- Консольный вывод - краткая сводка

### Текущие параметры:
- **RPS**: 5 запросов в секунду
- **Длительность**: 5 минут
- **Объём данных**: до 20 команд, до 200 пользователей
- **SLI времени ответа**: P95 < 300 мс
- **SLI успешности**: >= 99.9%

## Интерпретация результатов

- **total_requests**: общее количество запросов
- **request_rate**: скорость запросов (req/s)
- **success_rate**: процент успешных запросов
- **error_rate**: процент ошибок
- **avg_response_time**: среднее время ответа (ms)
- **p95, p99**: перцентили времени ответа (ms)
- **status_codes**: распределение HTTP статус-кодов
